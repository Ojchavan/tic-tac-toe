# Tic Tac Toe

A polished desktop Tic Tac Toe game built with Python and Tkinter — dark UI, score tracking, and cross-platform play.

## Features

- Dark-themed board with color-coded X / O
- Score and game counters
- Turn indicator and reset / new-game controls
- Runs on Windows, macOS, and Linux

## Requirements

- Python 3.x
- Tkinter (bundled with most Python installs)

## Run

```bash
git clone https://github.com/Ojchavan/tic-tac-toe.git
cd tic-tac-toe
python3 "Tic Tac Toe/main.py"
```
